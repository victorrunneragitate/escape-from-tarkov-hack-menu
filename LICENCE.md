## 🧩 About

**Escape from Tarkov Companion** is a curated list of Escape from Tarkov open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map overlay
- **Quality-of-Life Helpers** — inventory manager, ammo chart, quest helper
- **Research Notes** — raid layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Loot Tracker — highlight valuable items on the map
- Player Radar — show nearby players within a radius
- Extraction Helper — display extraction points and timers
- Ammo Chart — quick reference for ammo penetration and damage

### Wallhack
- Stash Manager — organize items with filters and sorting
- Item Finder — search stash and inventory for specific items
- Loadout Presets — save and load gear configurations

### Aimbot
- Interactive Map Overlay — view maps with markers and routes
- Quest Helper — show quest locations and objectives
- Spawn Points — display possible spawn locations for study
